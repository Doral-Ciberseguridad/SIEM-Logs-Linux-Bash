Pasos para ejecutar y usar esta herramienta:

1. Clona o descarga el repositorio en tu máquina ejecutando este comando:

```
git clone https://github.com/Doral-Ciberseguridad/SIEM-Logs-Linux-Bash.git
```

2. Instala las dependencias necesarias o asegúrate de contar con los requisitos del sistema ejecutando:

```
sudo apt update
```


3. Dale permisos de ejecución y lanza el script ejecutando en tu terminal:

```
chmod +x Analizador_Logs_SIEM.sh
```

```
./Analizador_Logs_SIEM.sh
```


4. Selecciona la opción que deseas realizar en el menú interactivo (del 1 al 3) para ver eventos en tiempo real, filtrar alertas críticas o configurar el envío por correo



5. Sigue las instrucciones en pantalla para elegir los logs, definir patrones de eventos o introducir la dirección de correo electrónico y monitoriza los resultados en el sistema
